# Simple_python_based_text_editor


## How to start

> caution note, My setup is on my phone, with termux (on another phone not on personal phone for security purposes)

---

> you need python and tkinter for this on your machine pls install it with your package manager

~~~
pkg update
pkg install python python-tkinter
~~~

## How to run it

-> download todo.py on your machine and "cd" to the location todo app is on

~~~
python3 editor.py
~~~
